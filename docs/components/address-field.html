Address field

A site's address, looked up as you type and kept in parts, each editable. Without a lookup service it's the same fields, typed by hand, so a product can add the lookup later.

Stablecomponents/address-field.csscomponents/address-field.jsUpdated 2026-10-29

When to use

  • Use it wherever an address is entered: a job site, a client, a lead, the company. Kept in parts, an address can be mapped, routed and sorted by area; a single line can't.
  • Show it on one line everywhere else: “1208 Barton Springs Rd, Austin, TX 78704” in a list or a record (D59).

Looking it up

The street line is a combobox whose list comes from a lookup service. Typing shows its suggestions; a pick fills the unit, city, state, code and country below, each still editable, and moves on to the unit, which no lookup knows. Nothing found keeps what's typed. The lookup is an aid, never a gate.

For Bolster’s build. The lookup is optional. Without it the street line is a plain field and the form is otherwise identical: nothing to wire, nothing lost. Adding a service later (Google Places, Mapbox, Radar…) means passing lookup, nothing else. Which service, and whether, is Bolster's call; the system needs only the answer's shape.

Countries

The country decides the parts' words, the state or province list and the postal code's check (D136). It starts as the company's.

CountryRegionPostal code
United StatesState, from the listZIP code: 78704 or 78704-1234
CanadaProvince, from the listPostal code: K1A 0B1, capitals and the space added
ElsewhereRegion, typed, optionalPostal code, as written, in capitals

Bolster's settings say “State/Province” and “Postal/Zip Code” for every country; the field says the one word that applies.

Layout

Its rows follow F-rows (Forms, D135): the street beside the unit (8 characters), the city beside the state (12) and the code (8), the country alone and full width. On phones every row stacks. It sits in a form section like any group of fields, with the section's spacing.

Accessibility

  • Each part has its own label and its autocomplete token (address-line1, address-line2, address-level2, address-level1, postal-code, country), so browsers and password managers can fill it too.
  • A change of country changes the labels, so what's read out always matches what's asked.
  • The street line follows the combobox's keyboard and announcements.

Every variant and state

Its specimen, live: the same markup and CSS a page uses, working (point, press, type), in this page's theme.

What's still open

  • The specimen lists 14 countries; a product lists them all (its own list, or the platform's names through Intl.DisplayNames).
  • No map pin, and no check that the address exists: the lookup's answer is taken as given.
  • The lookup service is Bolster's to choose (Google Places, Mapbox, Radar…); the system needs only the answer's shape.
