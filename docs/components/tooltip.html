Tooltip

A short label that names a control or an icon, on hover and keyboard focus. Every icon that stands without a label has one, drawn from data-tip.

Stablecomponents/tooltip.csscomponents/tooltip.jsUpdated 2026-11-02

When to use

  • Always on an icon that stands without a label (D52): an icon button (···, ×, Refresh), or an icon in content (the kinds in a table cell). A lone symbol (×, +, ⋯) counts as an icon.
  • Never for anything a person needs: there's no hover on a phone or a tablet. A rule, a reason or a value goes in the screen itself (helper text, the record).
  • Not on a control that shows its label. The label already says it.
  • Use a popover for an explanation of more than a phrase, such as how a figure is worked out.

Anatomy

A small dark label, 12px medium text on the tooltip surface, 4px corners, up to 16rem wide, just off what it names. It doesn't point: it sits centred above, or below when there's no room above, and stays 8px inside the window.

Two ways to add one

data-tip, the default

Put data-tip="…" on the icon or its control. tooltip.js draws one tooltip for the whole page, in the top layer, so no card, table or sheet clips it. It shows only while the element's own label isn't showing: a control that folds to an icon (the phone's search, Create folded to +) gets one, and the full one doesn't repeat itself.

<button class="button" data-variant="ghost" data-icon-only aria-label="Close" data-tip="Close">…</button>
<span class="cell-kinds" role="img" aria-label="Materials" data-tip="Materials">…</span>

A colour key (trying out)

Where a tooltip needs more than words (what a bar's colours are, with their figures), put a <template data-tip-html> inside the element holding a .tip-key: a row per colour, its dot from --_dot, its figure at the end. data-tip stays, as the text it falls back to, and the element's aria-label says the same for screen readers. The estimate's margin bar shows its cost split this way (D147). As with any tooltip, touch can't hover: say it somewhere else too.

.tooltip-anchor, CSS only

For a page without the script. The tooltip is markup beside its trigger, shown by CSS on hover and focus. It can sit on any side.

Its parent clips it like anything else positioned inside it, so in a card, a table or a sheet use data-tip.

ShowsAfter 300ms under a mouse, at once moving from one to the next; at once on keyboard focusAfter 150ms on hover; at once on keyboard focus

MotionFades, 120ms
FocusStays on the trigger; a tooltip is never focusable and never traps

Inside a modal dialog or sheet, the tooltip moves into it, so the dialog doesn't cover it. The rail is the one place without tooltips: it opens on hover and focus and shows every label (D24).

Content

  • The tooltip's words are the element's accessible name, word for word: data-tip and aria-label say the same.
  • Sentence case, the screen's own words (D27).

Accessibility

  • data-tip: the element keeps its own name in aria-label; the drawn tooltip is hidden from screen readers, so nothing is read twice.
  • .tooltip-anchor: role="tooltip" with an id. An icon-only trigger points at it with aria-labelledby, so the tooltip is its name; a trigger with its own label uses aria-describedby, so it adds detail.
  • Shows on keyboard focus as well as hover, so keyboard users get the same names.
  • scripts/check-tips.js (__tips() in the browser) lists every visible icon without one; run it at desktop and phone width with menus, sheets, the record and the bulk bar open.
