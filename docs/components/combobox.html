Combobox

Type to find a value in a long list, in the field itself: a client, a trade, the crew. The list narrows as you type, nothing matching offers to add one, several values sit as chips, and on phones the field opens the picker sheet.

Stablecomponents/combobox.csscomponents/combobox.jsUpdated 2026-11-02

When to use

  • Use a combobox for a list people search: clients, vendors, items, the crew, anything past about 15 values or growing.
  • Use a native select for a short fixed list that fits on screen: a type, a status (Field).
  • Use radios or a segmented control for two to five choices people should see at once (Checkbox, radio, toggle, Segmented control).
  • Use the address field for an address: it's a combobox on the street line, with the parts below it (Address field).

Anatomy

  1. Field. The field's own frame, label and states, with a chevron that says there's a list. A click, typing or ↓ opens it.
  2. List. Floats under the field, above everything (the top layer), so a dialog or a card never clips it. The menus' look: 12 corners, rows of 4, 8 in (D35).
  3. Row. The name, and under it what tells two apart: an address, a trade, never an id alone. The typed letters are marked.
  4. Active row. Where Enter lands: the first row while typing, moved with ↑ and ↓.
  5. The pick. Ticked when the list opens again.
  6. Add new. Last, after a rule, never above the options (I2), when nothing matches exactly.

Behaviour

WhenWhat happens
TypingThe list narrows at once, the first row ready for Enter. Ranked: the name's start, a word's start, anywhere in it, then the detail line. The count is announced politely.
↑ ↓ Enter↑ and ↓ move through the rows, round the end; Enter picks.
EscapeCloses the list and puts back what was there. A second Escape is the dialog's.
LeavingKeeps only a pick. A typed name that's an option is picked; where free text is allowed, what's typed stands; otherwise the field goes back to its pick.
Nothing matches“No clients match “zzz””, and “Add new client “zzz””, which opens the New client form with the name filled in. Saved, the new client is picked.
A long listAt most 50 rows: “50 of 240 shown. Keep typing to narrow them.”
From a serverNothing until something's typed; “Searching clients…” after 150 ms; a failure is said in the list.

Several values

The same component with data-multiple: each pick is a chip in the field, and the list stays open for the next. Picking a ticked row takes it off; a chip's × or Backspace in the empty field removes one. There's no separate tag input (D138).

The field stays one line, whatever the count, so it lines up with the fields around it. The chips that fit show in the order they were picked; the rest are counted, “+2”, with their names in its tooltip. The count opens the list, which shows the picks first, ticked, so every one is a click away. A case where a taller field would help is flagged for review, not built.

On phones

Under 640 wide, the field opens the picker sheet (Dialog, I2): the list's name as its title, the find box focused on top, the rows full width. A pick closes it; with several values, Done does. Focus doesn't go back to the field, so the keyboard stays down.

Content

  • The label names the value: “Client”, “Crew”, not “Search clients”. The placeholder can say it: “Search clients”.
  • The detail line is what people tell two apart by. Two Marco Ruizes differ by their address.
  • The add row says what it makes and with what: “Add new client “Rosa””.

Accessibility

  • The ARIA combobox pattern: role="combobox" on the input, aria-expanded, aria-controls to its listbox, aria-activedescendant to the active row. Focus stays in the field.
  • Rows are role="option" with aria-selected; the count after each change goes to a polite live region.
  • A chip's remove button is named (“Remove Ana Okafor”), and a removal is announced.
  • One row is highlighted at a time, where Enter goes: a fill, moved by the pointer and the keys alike. Moved with the arrow keys it also carries the focus ring, as a menu's rows do under the keyboard; what's picked is the tick, never the highlight (D152).

What's still open

  • With nothing typed the list starts from the top; recent or frequent picks first isn't there.
  • No groups in the list (people and companies; materials and labor).
  • Which fields take free text and which only pick from a list is set per field (free); there's no rule for it yet.
