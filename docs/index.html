The principles

Each one, with the decisions behind it

  1. Read for meaning, build by ruleA screenshot says what exists, never how it should look. Pages are made from a model and an intent by written rules.
  2. One meaning, one wayOne icon per meaning, one focus ring, one scroller, one status colour per stage. Sameness is what makes a product easy.
  3. The platform firstNative dialogs, popovers and inputs; plain CSS in layers. The browser's behaviour is the behaviour.
  4. Accessible from the startEvery text pair passes AA in both themes, every icon is named, every page is checked by machine.
  5. Colour carries meaningCalm, warm surfaces; colour only where it says something: a status, a warning, the one action that moves a job on.
  6. Said in the trade's wordsSentence case, the screen's own words, values as people say them. The words are part of the design.
  7. Built for the site and the office laptopPhones on a job site, a small laptop in the office: the page scrolls, the next step stays in reach.
  8. Decided once, written downEvery value and behaviour has a numbered decision and its reason, and checks that run themselves.
