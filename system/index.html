Bolster design system

List concept List page

The to-be system, as plain CSS. Start from bolster.css (everything) or import files one by one. Decisions behind each value are in docs/decisions.md; interaction contracts in docs/interactions.md.

Status quo · October 2026

This is the baseline to build on: warm in light (cement neutrals on a paper canvas), cool in dark (Bolster's greys), and the list page as the first page type made from it. It may still change a lot; until it does, new work starts here, and anything that disagrees with it is a change to make here first (D33).
