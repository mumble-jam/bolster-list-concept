Floating bar

Bulk actions for the rows you've ticked. It floats at the bottom of the screen, so the rows stay where they are while you select. Count first, then select all (or unselect all), the actions, the risky ones last after a rule, and clear. Inverse: dark in light, light in dark. Written to replace the other situational bars later (save changes, compare, move).

Rules

  • Only where the list has bulk actions (L-selection); never invent them.
