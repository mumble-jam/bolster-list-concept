Combobox

Type to find one value in a long list, in the field itself (D138, I26): a client, a trade, the crew. The list narrows as you type, the matched letters marked, the first row ready for Enter. Nothing matching offers to add one, at the end. On a phone the field opens the picker sheet. Every example works: type, use the arrows, Enter, Escape.

One value

240 clients: the list shows 50 and asks you to narrow them. A name and the line people tell clients apart by (their address). Typing a name that has no match offers “Add new client”, which opens the New client form with the name filled in.

21 trades, one picked. Click it to see the list, the pick ticked.

Several values

The crew on a job: each pick is a chip, and the list stays open for the next one. The field stays one line, whatever the count: the chips that fit, then “+3” for the rest (their names in its tooltip), which opens the list with the picks first, ticked. Pick a ticked row again to take it off; Backspace in an empty field takes off the last.

A lookup as you type

When the list lives on a server (an address lookup, a supplier's catalog): nothing shows until something's typed, “Searching addresses…” after a short wait, and what's typed stays where free text is allowed. The address field is built on it (Address field).

Try “barton”, “toronto” or “orchard”.

States

The field’s own: an error in words under it, disabled, and focus, which draws the field’s ring.

Rules

  • A list people search (clients, items, the crew, more than about 15): a combobox. A short fixed list: a native select. Two to five visible choices: radios or a segmented control.
  • The list narrows as you type; the first row is ready for Enter; the matched letters are marked. Each row carries what tells two apart (an address, a trade), never an id alone.
  • Escape puts back what was there. Leaving keeps only a pick, or what's typed where free text is allowed; a typed name that's an option is picked.
  • “Add new …” comes last, never above the options (I2), and opens the create form with what was typed: a client needs more than a name.
  • Several values: chips in the field, the list open for the next. The field stays one line: what doesn't fit is counted (“+3”). Never a second component for it.
  • On phones, the picker sheet: the find box on top, the rows full width, a pick closes it (Done, with several).
