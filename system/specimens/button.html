Button

One button component, named by role (D4). Primary is Bolster's black button with highlighter text; brand is the yellow call to action for the one step that moves a job forward ("Preview and send"). Blue is not a button colour: it's for links, focus and selection. Every state has a visible focus ring (D8). Primary, brand, danger and secondary have a body: an edge, a light line along the top, a shadow; hover lifts 1px and a press sinks at once, then eases back. Ghost is for places that already say "button" (toolbars, rows, bars, Close). Every button has 8px corners (D33).

Roles and states

Hover, active and focus are pinned with data-state for this page only. Use one primary per view; secondary for everything else, ghost inside toolbars and rows. Tertiary is gone: secondary covers it.

Rules

  • Labels start with a verb, sentence case, no trailing punctuation: "Create job", not "New" or "CREATE".
  • Icon-only buttons need an aria-label, and a tooltip if the icon isn't universal.
  • Don't override a button's height, radius or colours locally. If a variant is missing, add it here (the audit found 257 of 364 buttons with local overrides).
  • Show an action only when it applies. A disabled button needs a reason nearby.
  • A row or card that opens something is a link, not a button: see Data table and Card.
  • Red is for what can't be undone. Where Delete is one action of several it's a quiet danger (red text, fills red when pointed at); the filled red danger is only the confirmation's final button.
